常见问题

提交后多久可以生效？
实名认证由教务数据校验，通过后身份立即生效，页面会自动刷新为教师视角。
身份绑定错误怎么办？
可在个人中心执行“解除绑定”，随后重新提交正确的身份信息。
一个工号可以被多个账号绑定吗？
不可以。若工号已被其他账号绑定，系统会提示“该身份已被其他用户绑定”。
